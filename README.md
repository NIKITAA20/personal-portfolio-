# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio built using **React.js** showcasing my skills, resume, and certifications with a clean UI and smooth user experience.

🔗 **Live Website:**  
👉 https://nikita-portfolio-zeta.vercel.app/

---

## ✨ Features

- ✅ Responsive UI (Mobile + Desktop)
- 🎨 Clean & modern design
- 📄 Resume view & download
- 🎯 Skills & certifications section
- 🎥 Lottie animations
- 🔍 Search-based navigation
- ⚡ Fast loading & optimized
- 🌙 User-friendly interface

---

## 🛠️ Tech Stack

- **Frontend:** React.js  
- **Styling:** CSS3  
- **Animations:** Lottie  
- **Hosting:** Vercel  
- **Version Control:** Git & GitHub  

```bash
src/
│── assets/
│   └── lottie/
│
│── certifications/
│── resume/
│── dashboard/
│── skills/
│── experience/
│
│── App.js
│── index.js

```

## 🚀 How to Run Locally

```bash
git clone https://github.com/NIKITAA20/personal-portfolio-.git
cd personal-portfolio-
npm install
npm start
```
